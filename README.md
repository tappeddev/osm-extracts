# OSM extracts

Copies of OpenStreetMap extracts our builds use, so a build doesn't depend on the original download server. Each
release holds one file, unchanged, with its source and SHA-256.

Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under the
[Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/). The extracts are from
[Geofabrik](https://download.geofabrik.de/).
